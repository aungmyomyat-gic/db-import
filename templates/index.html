Excel → SQL Server Importer — how table scanning works.

Table တွေကို ဘယ်လိုရှာလဲ

App က user ရွေးထားတဲ့ Excel sheet ထဲက ■ 実施前テストデータ section ကိုပဲ ဖတ်ပါတယ်။ အဲဒီ section ထဲမှာ MZAIHP(...), MSHHNP(...) လို table name တွေကို ရှာပါတယ်။

  • Table row: table name ရှိတဲ့ row ဖြစ်ပါတယ်။
  • Header row: table name ရဲ့ အောက် row ကို header row လို့ယူပါတယ်။ → 更新前 / → 登録前 လို marker row ရှိရင် အဲဒီ row ကိုကျော်ပြီး နောက်တစ် row ကို header row လို့ယူပါတယ်။
  • Column range: header row မှာ ပထမ column ကနေ blank column မရောက်မချင်း ဖတ်ပါတယ်။ ဥပမာ B:AI လို့ပြပါတယ်။
